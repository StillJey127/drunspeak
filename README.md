# Друнспик

Голосовой чат, трансляция экрана со звуком, чат с картинками и файлами — на Python/UDP.

## Клиент

```bash
pip install numpy sounddevice mss pillow
pythonw client.pyw
```

По умолчанию клиент подключается к `drunspeak.playit.plus:5321`
(playit-туннель до локального сервера). Адрес и порт меняются в окне входа
или в `config.json` рядом с приложением.

Установщик (`drunspeaksetupprototype.iss`, Inno Setup) кладёт `client.pyw`,
`config.json` и `icons/` в `{app}` и создаёт ярлык, который передаёт каталог
приложения аргументом — поэтому настройки всегда читаются из папки установки.

## Сервер

```bash
pythonw server.pyw
```

Порт задаётся в `server_config.json`. В админ-панели: создание каналов с
паролем, перенос игроков между войсами, просмотр паролей каналов и аккаунтов
(последние хранятся только в ОЗУ).

## Протокол (UDP)

| Тег | Назначение |
|-----|------------|
| `J` | JSON-контроль (auth, userlist, chat, аватары, NACK, обновления) |
| `A` / `a` | голос 16 кГц int16 (`a` — со штампом ника) |
| `I` | чанки картинок чата |
| `F` | чанки файлов (до 300 МБ) |
| `V` | чанки кадров трансляции + XOR-FEC + маркер статичного кадра |
| `S` / `s` | звук трансляции 24 кГц (`s` — с session id) |

## Автообновления

При старте клиент тихо опрашивает `version.json` (3 зеркала), при наличии
новой версии предлагает обновиться. Для скриптовой установки качается
`client.pyw` с проверкой SHA256; для собранного exe открываются Releases.
Проверить вручную: «Настройки → Проверить обновления».

## Возможности

- 60 fps трансляция: конвейер grab→encode→send, FEC и быстрый NACK, дедуп статичных кадров.
- Захват звука системы через WASAPI loopback + fallback «Стерео микшер».
- Шумоподавление с overlap-add, пер-плеерная громкость и локальный мут.
- Кастомные темы: фото на всё окно + палитра из трёх цветов + предпросмотр.
- Свои каналы с паролем и отдельным чатом, передача файлов до 300 МБ.
- Статистика пинга (мин/макс/джиттер за минуту).

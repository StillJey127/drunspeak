# Загрузка на GitHub

Встроенный браузер агента **не авторизован** на GitHub (`Sign in`,
`Uploads are disabled`), а `git`/`gh` в системе не установлены — поэтому
залить файлы напрямую не получилось. Репозиторий `StillJey127/drunspeak`
существует и открыт в вашем браузере.

## Вариант 1 (быстрый) — перетащить архив

1. Распакуйте `drunspeak_github_upload.zip` в любую папку.
2. В открытом окне `https://github.com/StillJey127/drunspeak` нажмите
   **Add file → Upload files**.
3. Перетащите **все распакованные файлы** (и папку `icons/`) в область загрузки.
4. Commit message: `v3.7`, выберите `Commit directly to the main branch`,
   нажмите **Commit changes**.

GitHub сам обновит существующие `client.pyw` и `version.json` и добавит
остальные файлы. Важно залить `version.json` — иначе автообновления
у клиентов будут видеть старую версию 2.7.

## Вариант 2 — авторизуйтесь во встроенном браузере

Откройте вкладку агента (Review pane) с `https://github.com/login`,
войдите в аккаунт и скажите «залей» — тогда файлы будут загружены
автоматически через `Add file → Upload files`.

## Что внутри архива

| Файл | Назначение |
|------|------------|
| `client.pyw` | клиент v3.7 (SHA256 в `version.json`) |
| `server.pyw` | сервер |
| `version.json` | манифест автообновлений, версия 3.7 |
| `README.md` | описание протокола и запуска |
| `config.example.json` | пример конфига (playit.gg:5321) |
| `drunspeaksetupprototype.iss` | установщик Inno Setup |
| `client.spec` | PyInstaller-спек с папкой icons |
| `icon.ico` | иконка приложения |
| `icons/*.png` | 4 иконки интерфейса |

`config.json` с вашими личными данными в архив **не включён** — вместо него
`config.example.json`, чтобы не публиковать пароли и аватарку.

## После заливки

Автообновления заработают сразу:
- клиент при старте тихо опрашивает 3 зеркала `version.json`;
- при новой версии предлагает обновиться и качает `client.pyw` с проверкой SHA256;
- кнопка «Настройки → Проверить обновления» делает то же вручную;
- для собранного `exe` открываются Releases (нужен exe-ассет).

При следующем релизе достаточно обновить `client.pyw` + `version.json`
(новая версия, новый SHA256, новый `note`).
